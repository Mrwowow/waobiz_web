1. System Overview

The WaoBiz Hotel Management System (HMS) is a comprehensive solution for managing hotel operations including room bookings, guest management, pricing, and reporting.

Key Features

🛏️ Room Management

Manage room types and individual rooms

📅 Bookings

Create and manage reservations

💰 Pricing

Flexible pricing by season and day

📊 Reports

Comprehensive booking reports

Accessing the HMS Module

Menu → Hotel Management (HMS)

The HMS module can be accessed from the main sidebar menu. Look for the "Hotel Management" or "HMS" option.

HMS → Dashboard

The dashboard provides a quick overview of your hotel's current status.

3. Room Management

HMS → Rooms

3.1 Room Types

Room types define categories of rooms with similar features and pricing.

Creating a Room Type

1 Click + Add Room Type
2 Fill in the details:
  • Type Name: e.g., "Deluxe Room", "Standard Room"
  • No. of Adults: Maximum adult capacity
  • No. of Children: Maximum children capacity
  • Max Occupancy: Total persons allowed
  • Amenities: WiFi, TV, AC, etc. (comma-separated)
  • Description: Room description for guests
3 Click Save

3.2 Individual Rooms

After creating room types, add individual rooms with room numbers.

Adding Rooms

1 Click + Add Room
2 Select the Room Type from dropdown
3 Enter the Room Number (e.g., "101", "202")
4 Click Save
Room numbers must be unique. Use a consistent naming convention like floor number + room number (e.g., 101, 102 for first floor).

Room Type Summary

Deluxe Room 2 2 4 Couples, small families
Executive Suite 2 2 4 Business travelers, VIPs
Family Room 3 3 6 Large families

4. Pricing Configuration

HMS → Rooms → Pricing

4.1 Understanding Pricing Structure

The HMS supports flexible pricing based on:

  • Season Type: Regular season vs. Peak season
  • Day of Week: Different rates for weekdays/weekends
  • Room Type: Each room type has its own pricing

4.2 Setting Room Prices

1 Navigate to HMS → Rooms → Pricing
2 Select a Room Type
3 Choose Season Type (Regular or Peak)
4 Enter pricing:
  • Default Price per Night: Standard rate
  • Monday - Sunday: Day-specific rates (optional)
  • Per Adult/Child: Additional person charges
5 Click Save Pricing
Set weekend rates (Friday-Saturday) slightly higher to maximize revenue during high-demand periods.

4.3 Special/Seasonal Pricing

Use "Peak Season" pricing for holidays, festivals, and high-demand periods like:

  • Christmas & New Year
  • Easter holidays
  • Local festivals
  • Conference seasons
Always set both Regular and Peak season prices for each room type to avoid pricing errors during bookings.

6. Bookings Management

HMS → Bookings

6.1 Creating a New Booking

1 Click + New Booking
2 Guest Information:
  • Select existing customer or create new
  • Enter guest name, phone, email
3 Booking Details:
  • Arrival Date & Time: Check-in date/time
  • Departure Date & Time: Check-out date/time
  • Number of Adults: Adult guests
  • Number of Children: Child guests
4 Room Selection:
  • Click + Add Room
  • Select Room Type
  • Choose available room number
  • Confirm room rate
5 Add Extras (Optional):
  • Select additional services
  • Specify quantity if applicable
6 Apply Coupon (Optional):
  • Enter coupon code if available
  • Click "Apply" to get discount
7 Payment:
  • Review total amount
  • Select payment method
  • Enter payment amount
8 Click Save Booking

6.2 Booking Status

Status Description Action
🟡 Pending Awaiting confirmation Confirm or cancel
🟢 Confirmed Booking confirmed, awaiting arrival Check-in on arrival
🔵 Checked-in Guest has arrived Check-out on departure
⚫ Checked-out Guest has departed Booking complete
🔴 Cancelled Booking was cancelled Process refund if applicable

6.3 Editing a Booking

1 Find the booking in the list
2 Click the Edit button
3 Modify the necessary details
4 Click Update Booking
Changes to bookings may affect pricing. Always review the total before saving.

6.4 Printing Booking Confirmation

  • Print Full: Complete booking details (A4 format)
  • Print Receipt: Compact receipt format (80mm thermal)

7. Check-in & Check-out

7.1 Guest Check-in Process

1 Find the booking (search by guest name or booking ID)
2 Click Check-in button
3 Verify guest identity (ID card, passport)
4 Collect any pending payment
5 Confirm check-in time
6 Hand over room key and provide hotel information
7 Click Confirm Check-in
Standard check-in time is usually 2:00 PM. Early check-in may incur additional charges.

7.2 Guest Check-out Process

1 Find the booking
2 Click Check-out button
3 Review any additional charges (mini bar, room service, damages)
4 Add any extra charges if applicable
5 Process final payment
6 Collect room key
7 Click Confirm Check-out
8 Print final receipt/invoice
Standard check-out time is usually 12:00 PM (noon). Late check-out may incur additional charges.

9. Discount Coupons

HMS → Coupons

Create discount coupons for promotions and special offers.

9.1 Creating a Coupon

1 Click + Add Coupon
2 Enter coupon details:
  • Coupon Code: Unique code (e.g., "SUMMER20")
  • Discount Type: Percentage or Fixed Amount
  • Discount Value: Amount or percentage
  • Valid From/To: Validity period
  • Usage Limit: Maximum uses (optional)
3 Click Save

9.2 Coupon Types

Type Example Result
Percentage 20% ₦10,000 booking → ₦8,000
Fixed Amount ₦5,000 ₦10,000 booking → ₦5,000

9.3 Applying Coupons

During booking creation:

1 Enter the coupon code in the "Coupon" field
2 Click Apply
3 Discount will be reflected in the total
Ensure the coupon is still valid (check dates and usage limit) before applying.

13. Troubleshooting

Common Issues & Solutions

❓ Room not appearing in booking dropdown

Possible Causes:
  • Room is already booked for selected dates
  • Room is marked as unavailable
  • Room capacity doesn't match guest count
Solution: Check the calendar view and unavailability list

❓ Pricing showing as 0 or incorrect

Possible Causes:
  • No pricing set for the room type
  • Wrong season type configured
Solution: Go to Rooms → Pricing and ensure both regular and peak prices are set

❓ Cannot check-in guest

Possible Causes:
  • Booking status is not "Confirmed"
  • Arrival date is in the future
Solution: Confirm the booking first, then check-in

❓ Coupon code not working

Possible Causes:
  • Coupon has expired
  • Usage limit exceeded
  • Incorrect coupon code
Solution: Verify coupon details in Coupons section

Getting Help

If you encounter issues not covered here:

  • Contact your system administrator
  • Report the issue with screenshots
  • Note the exact steps that led to the error
